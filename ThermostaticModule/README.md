# 多阀门控制系统

## 系统功能

- 支持控制最多108个阀门，当前版本支持108个阀门
- 实时阀门状态监控和控制
- 正负压力控制系统
- 系统总开关控制
- Modbus通信接口
- 占空比控制
- 安全关机保护
- 支持通过界面直接修改阀门的开关频率和占空比

## 技术参数

### 设备连接参数

- 检测地址(CheckAddress): 0x700
- 服务器地址(ServerAddress): 
  - 0x41（控制阀门1-54）
  - 0x42（控制阀门55-108）
- 检查值(CheckValue): 0x00

### 压力控制范围

- 正压范围：0 ~ 1000 mBar（约合0 ~ 14.5 PSI）
- PSI转换为mBar系数：68.9476

## 寄存器地址说明

### 阀门控制寄存器 (0x800起始)

每个阀门占用5个连续的寄存器地址：

| 寄存器偏移 | 说明     | 取值范围       | 示例                    |
| ---------- | -------- | -------------- | ----------------------- |
| +0         | 开关状态 | 0:关闭, 1:开启 | 0x800 为阀门1的状态地址 |
| +1         | 频率值   | 0-10           | 0x801 为阀门1的频率地址 |
| +2         | 高电平值   | 0-999 （ms)    | 0x802 为阀门1的高电平时间地址 |
| +3         | 低电平值   | 0-999 （ms)    | 0x803 为阀门1的低电平时间地址 |
| +4         | 调试地址 |                |                         |


示例地址分布：

- 阀门1: 0x800-0x802
- 阀门2: 0x803-0x805
- 阀门3: 0x806-0x808
  （以此类推）

### 系统控制寄存器

| 地址  | 说明        | 取值范围       | 功能描述              |
| ----- | ----------- | -------------- | --------------------- |
| 0xA00 | 气压1设定值 | 0-1000 mBar    | 设置系统正压值        |
| 0xA20 | 占空比设定  | 0-1 (0%-100%)  | 设置阀门工作占空比    |
| 0xA02 | 系统总开关  | 0:关闭, 1:开启 | 控制系统整体运行状态  |

## 操作说明

1. 启动程序后等待设备连接（界面显示"连接成功"）
2. 设置正压值（单位：mBar），在输入框内输入数值后按回车键确认
3. 设置占空比（0-1之间），在输入框内输入数值后按回车键确认
4. 在表格中选择需要控制的阀门（可多选）
5. 使用启动/停止按钮控制选中阀门的操作
6. 可通过状态列的复选框单独控制各个阀门
7. 单击表格行可直接修改阀门的开关频率和占空比：
   - 修改频率：在`开关频率`输入框中输入新值并按回车键
   - 修改占空比：在`占空比`输入框中输入新值并按回车键
8. 系统启动后，启动按钮变为绿色并显示"系统已启动"
9. 点击停止按钮可安全关闭系统

## 用户界面元素

- 设备连接状态指示器：显示Modbus设备连接状态
- 阀门控制表格：包含阀门编号、频率、占空比和开关状态
- 正压设置输入框：设置系统正压值
- 实时正压值显示：显示当前系统正压读数
- 占空比设置：控制阀门工作周期
- 开关频率设置：控制阀门开关频率
- 启动按钮：启动选中的阀门并激活系统
- 停止按钮：停止所有阀门运行并关闭系统

## 安全特性

- 连接状态实时监控
- 系统紧急停止功能
- 压力范围自动校验（0-1000 mBar正压范围，-1000-0 mBar负压范围）
- 安全关机程序（关闭程序时提示用户先停止系统）
- 完整日志记录系统

## 运行环境要求

- Windows 7 或更高版本
- .NET Framework 4.7.2 或更高版本
